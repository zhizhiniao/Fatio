# 发条 Fatio 使用说明

## 第一次打开

1. 安装并打开“发条 Fatio”。首次安装不附带账号、草稿或演示资料。
2. 在“账号”添加需要的平台，通过官方窗口完成登录。需要扫码、验证码或身份确认时，由本人完成。
3. 点击账号切换右侧后台。每个账号拥有独立登录分区；重新登录时先核对昵称和身份。

## 准备一篇图文

1. 在“发图文”新建草稿，填写标题、正文并加入配图。编辑后保存。
2. 在“发布设置”勾选账号，需要时展开分平台设置，分别调整标题、正文、话题与 X 文案。
3. 查看预检提示，处理字数、图片数量和平台规则限制。
4. 加入队列后，按平台打开编辑器。核对图序、文字、封面和账号，再手动发表。
5. 稿件保留版本。修改源稿不会替换已经入队时保存的内容版本。

## 准备视频与封面

1. 在“发视频”选择一个或多个视频，为这批视频填写通用文案；每条视频可单独准备封面。
2. 在“封面工作室”提取视频帧或导入底图，根据目标平台检查尺寸、文字与裁切。
3. 可选择使用本机 Codex 生成候选封面。生成结果需要本人审阅，相关服务与额度另行准备。
4. 勾选账号并加入队列。同步中心逐账号准备投稿，最终在官方页面核对并发表。

## 排期与发表状态

- “发布队列”可切换列表和日历。排期任务可以调整日期，任务详情保留准备与核对状态。
- 网页排期是工作台准备安排，不代表电脑关机后还能替平台执行发布。
- 手动发表后，使用“核对发表状态”读取官方作品，或在详情明确选择本人已发布的作品。
- 匹配缺少证据时保留待核对；重名、审核中或时间不符时，不应直接认定成功。

## 稿件库、Obsidian 与 PostVela

1. 在稿件库绑定自己的图文制作目录或 Obsidian 仓库。
2. 从磁盘打开稿件会建立可编辑的工作台草稿。再次打开会复用草稿；需要新版本时主动重新载入。
3. PostVela 导出图集可在稿件库中按页查看 Live、GIF 和静态图，复制文案或打开素材文件夹。
4. 网页平台的动态图支持各不相同。小红书网页不支持 Live / GIF，抖音网页不支持 GIF；不能把静态备用图导入当作动态图发布成功。
5. 保留 Live Photo 需要通过手机相册和平台 App 验证；公众号长文 GIF 使用相应工具与有效接口权限。

## 作品数据与导出

- 在“数据 → 作品库”同步本人已授权账号的作品，进入详情查看原稿、作品链接和历史采样。
- 同一作品有可比较的有效采样后，才展示变化。缺失数值、过期采样和质量提示需要分别查看。
- 在“数据 → 导出到 NAS”选择本地或 NAS 目录。导出目录建议放在 Obsidian 仓库之外。
- 自动采样与定时导出依赖发条正在运行、平台登录有效及网络可用。可以在设置中查看状态或关闭。

## 备份与升级

程序默认位于 `%LOCALAPPDATA%\Programs\发条 Fatio`。兼容数据入口仍为 `%APPDATA%\JAStudio`；旧安装可能将其联接到另一目录，请备份实际目标。

升级前退出发条并备份资料。不要删除数据目录来解决程序目录名称问题。卸载、换电脑或降级前，先保存自己的草稿与素材。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 安装后出现登录页 | 在官方窗口重新确认登录；数据文件保留不保证平台会话一直有效 |
| 数据未更新 | 检查对应账号、网络和官方页面；查看采样覆盖与质量提示 |
| 已发表但队列仍待核对 | 用作品链接或作品 ID 核对，避免直接重发 |
| 打开稿件后图片不完整 | 核对源文件是否仍存在、目录绑定是否正确 |
| 视频号窗口打不开 | 核对 WebView2 是否安装，保留错误信息再反馈 |
| 某平台网页结构变化 | 保存原稿，先通过官方页面操作，并提交脱敏问题记录 |

具体支持范围见 [STATUS.md](STATUS.md)。

## 接收软件更新

1.12.3 起可从左下角“检查更新”查看本机与公开版本。默认启动后和运行期间自动检查，每 6 小时最多一次；发现新版后入口会显示“发现新版”。

点击查看版本说明和下载入口。下载完成后退出发条，再运行安装包；原账号和草稿继续保留。可跳过某个版本或关闭自动检查，之后仍可手动检查。

旧版 1.12.2 没有更新检测，需要先手动安装一次新版本。网络或 GitHub 暂时不可达时会显示失败原因，稍后重试即可。
