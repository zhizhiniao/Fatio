# 功能与验证范围

更新：2026-11-15 · 适用版本：1.12.3 开发者预览版。

## 当前能力

| 模块 | 已实现 | 边界 |
| --- | --- | --- |
| 软件更新 | 启动与运行期间自动检查、手动检查、版本说明和下载入口 | 1.12.2 需手动升级一次；网络和 GitHub 可用性影响检查 |
| 账号与登录 | 官方后台窗口、独立会话、账号切换与身份核对 | 需要本人登录；会话过期、验证码和平台权限由官方流程决定 |
| 图文与视频 | 草稿版本、配图、批量视频、分平台文案与封面准备 | 平台允许的素材与格式各不相同 |
| 发布队列 | 任务归组、月历/周历、改期、打开投稿页与回执核对 | 网页最终发表由本人完成；电脑关闭后不能替网页执行 |
| 作品与指标 | 本人作品同步、历史采样、原稿关联和质量提示 | 不同平台字段覆盖不同；缺失与过期数据需要保留其标记 |
| 稿件来源 | 自选 Markdown、Obsidian 与 PostVela 图集目录 | 作者工作流中的默认路径在其他电脑上需自行重新绑定 |
| NAS 导出 | 只读 JSON 数据快照、运行期间自动导出 | 需要可写目录；不含登录态、密钥和稿件正文 |
| Codex 协作 | 文案候选、检查与可选封面生成 | 需要用户自行安装并登录相关工具，不能视作随包附送的模型服务 |

## 验证证据

- 核心自动化回归覆盖账号身份、草稿与队列、素材校验、平台数据、发表回执、图集导入、数据采样与 NAS 导出。
- 本次安装验证覆盖“发条 Fatio”中文目录、安装登记、桌面/开始菜单入口与程序版本。
- 迁移前后比较真实账号、草稿、素材、视频和任务记录，以及 Local State / Cookie 文件；比较结果写入本机私有验收目录，不随公开仓库发布。
- 安装版隔离演示检查独立数据路径、账号/草稿/任务保存，以及工作台、编辑器和日历渲染；公开截图仅使用演示资料。
- 历史实号核验是在开发者的账号与当时平台页面下取得，不代表其他账号、地区或未来页面仍然通过。

本次具体通过数量与迁移结果见[版本记录](releases/v1.12.2-dev.1.md)。

## 仍需验证

- 干净电脑、更多 Windows 版本、不同网络与账号权限。
- 所有平台的真实视频/图文发表与发表后的完整数据回读。
- iPhone Live Photo 相册导入，以及小红书、抖音 App 的动态播放与发布。
- 平台结构变化、长期登录保留、所有 API 权限组合和异常网络恢复。
- 程序尚未做代码签名，预览版不承诺长期接口稳定性。

遇到未覆盖的情况，请保存原稿并提交脱敏问题，不将“准备完成”直接记作“公开发布成功”。
