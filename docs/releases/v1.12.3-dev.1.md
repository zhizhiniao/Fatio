# 发条 Fatio 1.12.3 开发者预览版

2026-11-15 · Windows x64。

## 自动收到更新提示

- 启动后自动检查 GitHub 公开版本，运行期间每 6 小时最多检查一次。
- 发现新版后，左下角入口显示“发现新版”。点击查看版本说明、预览版标记并下载 Windows 安装包。
- 可手动重新检查、跳过此版本或关闭自动检查。跳过后续新版本仍会提示；更新结果与偏好在重启后保留。
- 网络不可达或服务限流会显示原因与重试提示，不影响账号、草稿和发布工作。
- 只查询公开版本信息，不向更新服务上传账号或草稿。下载入口仅接受本项目的 GitHub 安装包。

## 旧用户需要做一次手动升级

**1.12.2 及更早版本没有更新检测代码，必须先手动安装 1.12.3。** 装上本版后，后续更高版本可自动检测并提示。

点击“下载更新”后，在浏览器完成下载；退出发条，再运行安装包升级。本版提供自动检查与提示，安装由用户主动完成。账号、草稿、素材和登录分区继续使用原数据目录。

默认程序目录仍为 `%LOCALAPPDATA%\Programs\发条 Fatio`。安装包尚未做代码签名，请核对本发布页和同页 `SHA256SUMS.txt`。

## 验收

- 核心回归 86/86 通过。
- 安装版隔离界面：启动缓存提示、手动检查、下载入口、纯文本版本说明、窄窗口、跳过版本与自动检查偏好跨重启保留，以及后续更高版本再次提示均通过。
- 使用新安装包升级至 1.12.3，安装器退出码 0；账号、草稿、素材、视频、任务及登录相关文件升级前后校验一致。

## 后续发布约定

每次功能发布提升 `package.json` 的程序版本号；公开相应 GitHub Release，并上传 `Fatio-Setup-版本号-x64.exe` 和校验文件。检测同时覆盖本项目的开发者预览版与正式版；草稿、未上传完整安装包或版本号不高于本机的发布不会提示升级。

此流程不需要用户重新配置 API 或登录开发者账号；能否及时访问更新服务取决于网络。其他电脑、长期运行和所有平台真实投稿仍需更多使用验证。
