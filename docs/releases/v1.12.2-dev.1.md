# 发条 Fatio 1.12.2 开发者预览版

2026-11-15 · 首次公开 GitHub 发布 · Windows x64。

## 这次更新

- 程序默认安装目录统一为 `%LOCALAPPDATA%\Programs\发条 Fatio`，升级时不再自动沿用带历史产品名的程序目录。
- 桌面与开始菜单统一使用“发条 Fatio”，指向同一份安装程序。
- 继续使用原有数据身份，保留账号、草稿、素材、队列及登录分区。
- 提供完整中文 README、上手说明、平台支持与验证边界，以及作者微信联系方式。

## 预览版已有能力

账号后台切换、图文与视频草稿、分平台文案和封面、发布队列与日历、本人作品和指标采样、Markdown / Obsidian / PostVela 稿件接入，以及可选 NAS 数据导出。

网页流程会准备素材并打开官方后台，最终发表需本人核对。平台登录、权限、网络和页面结构分别影响可用能力。

## 下载与校验

下载 `Fatio-Setup-1.12.2-x64.exe`，与同页 `SHA256SUMS.txt` 核对 SHA-256。安装器尚未做代码签名。

## 升级提示

退出发条后安装。数据入口仍为 `%APPDATA%\JAStudio`；部分旧安装会将其联接到其他位置，请备份实际目标。不要删除该目录来整理程序名称。

新目录安装会更新安装登记和同名快捷方式；其他旧程序目录中的未知文件不会自动删除。确认新版本和旧资料均可读取后，再清理旧程序文件。降级前另行备份当前资料。
